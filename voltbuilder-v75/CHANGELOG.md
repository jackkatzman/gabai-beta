# GabAi v3.0.75 - Enhanced User Experience

## Release Date: September 30, 2025

### 🐛 Bug Fixes
1. **Fixed Checkbox Styling**: Checkboxes are now properly sized (24x24px) and easier to tap
2. **List Name Saving**: Fixed the list name edit and save functionality 
3. **Sharing Options**: Enhanced sharing functionality for SMS, WhatsApp, and Email

### 🎨 UI Improvements
1. **Better Checkbox Design**: Square checkboxes with proper aspect ratio and tap targets
2. **Increased Touch Targets**: 40x40px minimum tap area for better mobile usability
3. **Fixed Oblong Issue**: Checkboxes now maintain proper shape on all devices

### ✨ Features
1. **Editable Shared Lists**: Users can now set shared lists as "View Only" or "Can Edit"
2. **Enhanced List Management**: Improved list name editing with save functionality
3. **Better Mobile Experience**: Optimized touch interactions and visual feedback

### 🚀 Performance
1. **Improved Build Process**: Enhanced deployment configuration for Cloud Run
2. **Better Error Handling**: Added comprehensive server error reporting
3. **Optimized Assets**: Frontend and backend optimizations for faster loading

### 📱 Mobile Specific
1. **Fixed APK Checkbox Issues**: Resolved the oblong checkbox rendering problem
2. **Improved Touch Response**: Better tap detection and visual feedback
3. **Enhanced Sharing**: All sharing methods now work properly in APK
